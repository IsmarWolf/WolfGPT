# Llama-WolfGPT-110M

**Built with Llama.**

A 110-million-parameter chat model, trained completely from scratch (random start, no pretrained weights) by **Explorer** on a single RTX 5060 Ti 16 GB. It is a learning project: every step is documented, and the model is meant as a demonstration of chatting, not as a reliable assistant. When you chat with it, it calls itself WolfGPT.

> Why "Llama-" in the name: part of the fine-tuning conversations were written by Llama 3.1 405B-Instruct (see "Use of Llama" below). The Llama 3.1 Community License requires "Llama" at the beginning of the name of any distributed AI model trained on Llama outputs, so the published name is Llama-WolfGPT-110M.

## Use of Llama (what was and was not used)

| Item | Used? |
|---|---|
| Llama model weights as a starting point | **No.** WolfGPT was initialised randomly and pretrained from scratch. |
| Llama code, tokenizer or architecture files | **No.** The model code, optimizer and a 32,768-token BPE tokenizer were written/trained for this project. (The design uses ideas common to modern models: RoPE, RMSNorm, SwiGLU.) |
| **Text generated by Llama 3.1 405B-Instruct** | **Yes.** The subset *smol-magpie-ultra* of HuggingFaceTB/smol-smoltalk was produced with the Magpie method and Llama-3.1-405B-Instruct. It is about 57% of the fine-tuning conversations (270,838 of 477,612 before de-duplication, 2026-11-12 run). Its outputs were used for supervised fine-tuning (SFT) of WolfGPT. |
| Other fine-tuning subsets | Not verified one by one. The dataset card names Llama 3.1 only for smol-magpie-ultra; the everyday-conversations subset is described as coming from a Llama-3.1-related source that the card does not detail. Treat that subset as possibly Llama-generated as well. |

## Quick start

```
pip install torch tokenizers safetensors
python chat.py                      # chat in the terminal (empty line quits, /reset = new chat)
python chat.py --temperature 0.7 --retries 0 --show_flags
```

Files: `model.safetensors` (weights, float32), `config.json`, `tokenizer.json` (32,768-token BPE), `model.py` (the architecture), `chat.py` (chat with repeat-protection), `benchmarks.json`, `NOTICE`, `LICENSE`.
The model is not a Hugging Face `transformers` architecture: use `model.py`/`chat.py` from this repository.

Chat format used in training: `### User:\n{message}\n\n### Assistant:\n{answer}<|endoftext|>`.
`chat.py` rejects and re-generates a reply that mostly repeats an earlier reply (`--retries`, default 3), and cuts a reply at a stray `###`.

## Model details

- Architecture: decoder-only transformer, 12 layers, 12 heads, width 768, context 1,024 tokens, vocabulary 32,768, tied embeddings, RoPE, RMSNorm, SwiGLU. 110,119,680 parameters.
- Pretraining: about 3.0B tokens of FineWeb-Edu (sample), optimizer Muon + AdamW, bf16, about 18 hours. Validation loss 3.129.
- Fine-tuning (SFT): 446,353 conversations (267.5M tokens) from smol-smoltalk, everyday-conversations and Databricks Dolly 15k, 2 epochs, loss only on answer tokens. Validation loss 2.395 -> 1.484.
- Identity stage: 300 hand-written conversations (name, maker, limits) mixed with 10,000 ordinary chats; this is what makes it answer "I'm WolfGPT... built by Explorer".
- Chat format: `### User:\n{message}\n\n### Assistant:\n{answer}<|endoftext|>`

## Benchmarks (zero-shot, full test/validation sets, plain-text prompts without the chat template)

Scored by comparing the likelihood the model gives to each answer text (no choices shown), with a small custom script, not lm-evaluation-harness (raw numbers: `benchmarks.json`). Score shown per task is the usual one (acc_norm; acc for Winogrande). The plus-minus is the approximate standard error from the number of questions.

| Task (questions) | Random | Base model (after pretraining) | Chat model after SFT | Llama-WolfGPT-110M (SFT + identity) |
|---|---|---|---|---|
| HellaSwag (10,042) | 25 | 32.3 (±0.5) | 30.9 | 31.1 |
| ARC-Easy (2,376) | 25 | 48.2 (±1.0) | 40.5 | 40.3 |
| ARC-Challenge (1,172) | 25 | 26.0 (±1.3) | 24.9 | 24.6 |
| PIQA (1,838) | 50 | 62.2 (±1.1) | 59.2 | 58.4 |
| Winogrande (1,267) | 50 | 51.7 (±1.4) | 49.6 | 51.1 |

Reading the table: the model is clearly above chance on HellaSwag, ARC-Easy and PIQA, and at chance on ARC-Challenge and Winogrande, which need more reasoning than a 110M model has. Chat fine-tuning lowered the ARC-Easy score by about 8 points and PIQA by about 3. This is expected when a model is tuned for conversations, and it is partly because these tests use plain text instead of the chat format; it was not tuned or filtered to protect these scores. Numbers from different evaluation code are only roughly comparable.

## Limitations

- Small model: facts are often wrong, arithmetic is unreliable, it may ignore length instructions and repeat itself.
- It invents stories when role-played at (for example it made up a backstory when told "I'm your father").
- English only. Not tested for safety; do not use for anything important.
- Small models repeat themselves in long chats and answer vague or one-word messages poorly. `chat.py` defaults (temperature 0.4, repetition penalty 0.3, retries 3) were chosen for that; `/reset` clears the chat.

## Example (temperature 0.3, repetition penalty 0.3)

```
You> who are you?
WolfGPT> I'm WolfGPT, a small language model. I can chat, answer simple questions, and help with short writing.
You> who made you?
WolfGPT> I was built by Explorer, a game nickname.
You> What is the capital of Japan?
WolfGPT> The capital of Japan is Tokyo.
```
